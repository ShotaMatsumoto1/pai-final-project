# 機械学習を活用した日本語命令によるロボット操作

Physical AI 応用1講座の最終課題向け実装です。日本語の移動命令を scikit-learn で5種類の動作に分類し、ROS 2 経由で Gazebo の差動二輪ロボットを動かします。

## 課題の目的

シミュレータ上のロボットに、日本語の命令で前進・後退・左旋回・右旋回・停止を行わせる。分類できない命令では動かさない。

## 使用技術

- ROS 2 Jazzy
- Gazebo Harmonic（公式デモ `ros_gz_sim_demos` の `diff_drive`）
- Python 3.12
- uv（仮想環境はシステムの ROS 2 パッケージを参照する）
- scikit-learn（文字 n-gram の TF-IDF とロジスティック回帰）

深層学習、強化学習、有料 API、自作ロボットモデルは使っていません。

## システム構成

```text
日本語の入力
  -> 複数方向・逆接の拒否
  -> TF-IDF（文字 1〜3 gram） + ロジスティック回帰
  -> 出力スコアとマージンの閾値
  -> geometry_msgs/Twist
  -> /model/vehicle_blue/cmd_vel
  -> ros_gz_bridge
  -> Gazebo vehicle_blue（DiffDrive）
```

制御対象は青いロボットだけです。速度指令の型は `geometry_msgs/msg/Twist` で、Gazebo 側は `gz.msgs.Twist` です。この対応はローカルの公式 launch ファイルと、起動中のブリッジ出力で確認しています。

「少し」「ゆっくり」は速度や移動距離に反映しません。動作は固定です。

| 分類 | 速度 | 時間 |
|---|---|---|
| forward | 前進 0.4 m/s | 2.0 秒のあと停止 |
| backward | 後退 0.4 m/s | 2.0 秒のあと停止 |
| left | 左旋回 0.8 rad/s | 2.0 秒のあと停止 |
| right | 右旋回 0.8 rad/s | 2.0 秒のあと停止 |
| stop | 速度 0 | 停止指令を送る |

公式モデルの速度上限は並進 0.5 m/s、旋回 1 rad/s です。指令値はその内側にしています。

## AIモデルの概要

起動のたびに `data/train.csv` から学習します。モデル本体は次の構成です。

```python
make_pipeline(
    TfidfVectorizer(analyzer="char", ngram_range=(1, 3)),
    LogisticRegression(max_iter=1000, random_state=0),
)
```

動作クラスは forward、backward、left、right、stop の5つです。これに加え、挨拶や質問、複数動作が混ざった文を `unknown` として学習し、そのクラスを予測したときは動かしません。

ロジスティック回帰の `predict_proba` は、そのまま正解確率とはみなしません。採用判定には次の2つを使います。

- 出力スコア: 最大クラスの出力値
- マージン: 1位と2位の差

閾値は学習データでは決めません。`data/calibration.csv` だけで、動作クラスへ誤って寄った例の最大値と、正しく分類できた例の中央値の中間を取ります。現在の実測値は次のとおりです。

- 出力スコアが 0.391480 より大きい
- マージンが 0.158897 より大きい

左右が同時に含まれる文、前後が同時に含まれる文、逆接（「ただし」「しかし」など）を含む文は、スコアに関係なく拒否します。空の入力も拒否します。

## 学習データの説明

文章の重複はありません。評価文は学習にも校正にも入れていません。

| ファイル | 役割 | 件数 |
|---|---|---|
| `data/train.csv` | 学習 | 210 |
| `data/calibration.csv` | 閾値決定 | 60（動作 40、拒否 20） |
| `data/eval.csv` | 未使用文の評価 | 58（動作 40、拒否 18） |

学習データの内訳は、forward 32、backward 34、left 32、right 32、stop 34、unknown 46 です。動作5クラスはいずれも30件以上です。

## ロボット制御の仕組み

1. 命令を分類する。
2. 拒否のときは速度指令を送らない。
3. 受理したときは 10 Hz で速度を送り、約2秒後にゼロ速度を送る。
4. 動作中に停止分類の命令が来たら、その場でゼロ速度を送る。
5. 終了時と例外時にもゼロ速度を送る。

## 実行手順

### 依存関係

このリポジトリの環境では、ROS 2 Jazzy、Gazebo Harmonic、uv、scikit-learn を導入済みです。別の Ubuntu で再現する場合は、ROS 2 Jazzy と Gazebo Harmonic、`ros_gz_sim_demos` を用意したうえで、次を実行します。

```bash
source /opt/ros/jazzy/setup.bash
uv venv --python /usr/bin/python3 --system-site-packages
source .venv/bin/activate
uv pip install "scikit-learn>=1.4"
```

`uv sync` は仮想環境を作り直すことがあり、ROS 2 の Python パッケージが見えなくなることがあります。このプロジェクトでは `uv venv --system-site-packages` と `uv pip install` を使います。

### 起動

ターミナルを2つ使います。

```bash
# ターミナル1: Gazebo とブリッジ
./scripts/start_gazebo.sh

# ターミナル2: 日本語命令
./scripts/run_robot.sh
```

Gazebo の `diff_drive` が既に動いていて、ブリッジだけが無い場合は、ターミナル1を次に置き換えます。

```bash
./scripts/start_bridge.sh
```

`RVIZ=true ./scripts/start_gazebo.sh` で RViz も開けます。ロボットの確認には Gazebo の画面で足ります。

プロンプトへ日本語を入力します。終了は `exit` です。動作中に「止まれ」と入力すると、その動作を中断します。

分類だけを再評価する場合:

```bash
source .venv/bin/activate
python -m jp_command_robot.evaluate
python -m unittest tests.test_classifier tests.test_controller
```

Gazebo とブリッジが動いているときの動作確認:

```bash
source /opt/ros/jazzy/setup.bash
source .venv/bin/activate
python -m jp_command_robot.sim_check
```

## テスト結果

数値は 2026-10-12 にこの環境で測ったものです。学習データそのものの正解率は成果指標にしていません。

### 未学習の日本語

動作命令 40 件のうち、受理かつ正解は 33 件（0.8250）でした。残りの 7 件は拒否され、別方向への移動はありません。拒否用 18 件は 18 件とも不受理でした。

指定された10文は、いずれも学習データに含まれておらず、次の結果でした。

| 命令 | 分類 | 出力スコア | マージン |
|---|---|---:|---:|
| 前に進め | forward | 0.4955 | 0.2739 |
| まっすぐ進んで | forward | 0.4347 | 0.2424 |
| 後退してください | backward | 0.4605 | 0.3336 |
| 後ろに下がれ | backward | 0.6074 | 0.4561 |
| 左に曲がって | left | 0.6602 | 0.5337 |
| 左折してください | left | 0.4878 | 0.3262 |
| 右に回転して | right | 0.5133 | 0.3641 |
| 右折して | right | 0.5456 | 0.4171 |
| 止まって | stop | 0.7663 | 0.6839 |
| 停止してください | stop | 0.6026 | 0.5046 |

閾値で拒否した未学習の動作文は次の7件です。6件は第1候補の分類自体は期待どおりで、スコアかマージンが閾値以下でした。「動かずにいて」だけは unknown でした。

- 直進してください（forward、スコア 0.3792、マージン 0.1999）
- 正面に移動して（forward、スコア 0.3629、マージン 0.1690）
- 前へ進み続けて（forward、スコア 0.3860、マージン 0.1390）
- 後進をお願いします（backward、スコア 0.2455、マージン 0.0509）
- 左回転してください（left、スコア 0.3892、マージン 0.1852）
- 動作を止めてください（stop、スコア 0.3419、マージン 0.1668）
- 動かずにいて（unknown、スコア 0.2915、マージン 0.0245）

「進め、ただし止まれ」のモデル出力はスコア 0.4530、マージン 0.2322 で、数値だけでは動作閾値を超えます。逆接を含むため規則で拒否し、ロボットには送っていません。「前か後ろに動いて」もスコア 0.4135、マージン 0.1828 で閾値を超えますが、前後が同時に含まれるため拒否しています。

### Gazebo 上の移動

起動中の `diff_drive` ワールドで、`/model/vehicle_blue/odometry` の変化を測りました。オドメトリの配信は公式 SDF の設定で 1 Hz です。画面の目視はこの確認には含めていません。

| 確認 | 結果 |
|---|---|
| 前に進め | 車体前方へ 0.758 m |
| 前進後の停止 | 追加変位 0.000 m |
| 後ろに下がれ | 車体前方へ -0.749 m |
| 左に曲がって | yaw +1.570 rad |
| 右折して | yaw -1.491 rad |
| 前進を 0.4 秒で中断 | 前方変位 0.159 m。その後の変位 0.000 m |
| こんにちは | 変位 0.000 m、yaw 変化 0.000 rad |

`python -m jp_command_robot --once` で「こんにちは」の拒否と「止まれ」の停止指令を再実行し、終了できました。単体テスト 12 件は成功しています。

## 独自に工夫した点

- 公式の差動二輪デモはそのまま提出せず、日本語分類と速度指令のプログラムを別に作った。
- 動作5クラスに加え、動かさない文を unknown として同じモデルで学習した。文字 n-gram では「名前」の「前」が前進に寄りやすいため、名前や前回などの文を unknown に入れている。
- 評価文を学習と閾値決定から分離し、出力値を正解確率とみなさずに校正データで閾値を決めた。
- 左右・前後の同時指定と逆接は、スコアが高くても動かさない。
- 動作後、中断時、終了時、例外時に停止指令を送る。

## 制限事項

- 速度と移動時間は固定で、障害物の回避や自己位置を使ったナビはない。
- 緑のロボットは制御しない。
- 学習例から離れた言い回しは、誤った方向へ動くより拒否する。上記7件がその例である。
- 実機では未確認である。
- Gazebo のウィンドウを見ての確認は、この実装時には行っていない。移動の判断はオドメトリである。
