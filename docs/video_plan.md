# 動作動画の撮影構成

長さは約2分です。1分以上、3分以内に収めます。Gazebo の画面と、日本語を入力する端末が同時に見えるように撮ります。青いロボットだけを映します。左右の命令は、前に進まずその場で旋回します。

撮影前に、次の2つだけを起動します。

```bash
# ターミナル1
./scripts/start_gazebo.sh

# ターミナル2
./scripts/run_robot.sh
```

| 時間 | 画面 | 内容 |
|---|---|---|
| 0:00-0:15 | Gazebo | `diff_drive` が起動し、青いロボットが止まっていることを見せる |
| 0:15-0:30 | 端末 | 制御プログラムを起動し、閾値が表示されるところを見せる |
| 0:30-0:50 | 両方 | 「前に進め」と入力し、約2秒進んで止まる |
| 0:50-1:10 | 両方 | 「左に曲がって」と入力し、その場で左へ回って止まる |
| 1:10-1:25 | 両方 | 「右折して」と入力し、その場で右へ回って止まる |
| 1:25-1:45 | 両方 | 「後ろに下がれ」と入力し、後退して止まる |
| 1:45-1:55 | 両方 | 「止まって」と入力し、動かないことを見せる |
| 1:55-2:10 | 端末中心 | 「こんにちは」と「進め、ただし止まれ」が拒否され、ロボットが動かないことを見せる |
| 2:10-2:20 | 両方 | `exit` で終了する |

撮影前に、ロボットが壁やもう一台のロボットに近づきすぎていないことを確認します。動きが分かりにくいときは、上の命令のあいだを少し空けます。ナレーションは入れなくても、端末の分類結果が見えれば内容は伝わります。
